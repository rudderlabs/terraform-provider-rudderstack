# rudderstack_destination_singular (Resource)

This resource represents a Singular destination. For more information check
https://www.rudderstack.com/docs/destinations/streaming-destinations/singular/

## Example Usage

```terraform
resource "rudderstack_destination_singular" "example" {
  name = "my-singular"

  config {
    api_key = "your_api_key_here"

    connection_mode {
      android = "device"
      ios     = "device"
      web     = "cloud"
    }
  }
}
```
