# rudderstack_transformation_connection (Resource)

This resource connects an existing (published) Rudderstack Transformation to an existing Destination.

A destination can have only one connected transformation at a time; connecting a transformation to a destination replaces any transformation already connected to it. The transformation must be published before it can be connected.

## Example Usage

```terraform
resource "rudderstack_transformation_connection" "example" {
  transformation_id = "2C8Vk2wj8qkofy00YzJbvJOGeqa"
  destination_id    = rudderstack_destination_redshift.example.id
}
```
