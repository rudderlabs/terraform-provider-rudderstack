# rudderstack_account_source_postgres (Resource)

This resource represents a Postgres rETL account for storing warehouse credentials used in reverse-ETL pipelines. For more information check
https://www.rudderstack.com/docs/sources/reverse-etl/postgresql/

## Example Usage

```terraform
resource "rudderstack_account_source_postgres" "example" {
  name = "my-postgres-account"
  config {
    host   = "db.example.com"
    dbname = "analytics"
    user   = "rudder"
    port   = "5432"
    # "disable" (default) or "require".
    ssl_mode = "require"
    # Keep the password out of version control (use a variable or a secret store).
    password = var.postgres_password
  }
}
```
